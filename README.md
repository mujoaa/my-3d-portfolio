# 余白 / YOHAKU

コーヒー、ギター、小説、バイク。好きなものを巡る、日本語の3Dポートフォリオ。

**公開先:** https://mujoaa.github.io/my-3d-portfolio/

**TypeScript + Three.js + Vite**。React / Next.js は使っていません。

## ローカルで動かす

Node.js 22.12 以降（推奨: Node.js 22 LTS）と npm を使用します。

```sh
npm ci
npm run dev
```

ターミナルに表示されるURLをブラウザーで開きます。

```sh
npm run check     # TypeScript の型チェック
npm run build     # 型チェック後、dist/ に生成
npm run preview   # 本番ビルドのプレビュー
```

## GitHub Pages

1. このリポジトリの **Settings → Pages → Source** を **GitHub Actions** に設定します。
2. `main` への push で `.github/workflows/deploy.yml` が動きます。
3. `npm ci` → 型チェック → ビルド → Pagesへのデプロイを自動実行します。
4. **Actions** の実行が成功すると、上記の公開URLで見られます。

Vite の `base: './'` により、リポジトリ名を含むサブディレクトリでも画像やスクリプトを読み込めます。独自ドメインや秘密のトークンは不要です。リポジトリ名を変えたら、このREADMEと `index.html` のGitHubリンクも更新してください。

## 表現と操作

- 4章構成。通常のページスクロールで3Dオブジェクトの回転と切り替えが進みます。
- 目次、次の章、右端のナビゲーションから各章へ直接移動できます。
- 3Dモデルは基本形状から生成したオリジナル。外部GLB・動画・モデル配布サービスを使いません。
- バイクはオリジナルのクラシックスタイルの造形です。実在する車種の精密モデルではありません。
- 日本語の紹介文は、4つの趣味をもとにした初稿です。固有の愛用品やプロフィールは自由に書き換えてください。

## 軽量化・アクセシビリティ

- 本文は静的HTML。JavaScriptが無効でも、本文・章リンク・SVGイラストを読めます。
- 3Dは動的import。静止画表示では3Dのコードを最初に読み込みません。
- タッチ端末または狭い画面はDPR最大1.25、最大30fps、形状の分割数を削減。デスクトップはDPR最大1.7、最大60fpsです。
- シャドウマップ・ポストプロセス・大きな画像テクスチャを使いません。タブ非表示時と3Dオフ時は描画を停止します。
- `prefers-reduced-motion: reduce` では最初から静止画にし、スムーズスクロールも停止します。明示的に3Dを有効にしても連続した浮遊アニメーションは行いません。
- ページ右上の **3D ON / OFF** で切り替え可能。`?no3d` をURL末尾に付けると静止画から始まります。
- WebGL非対応、初期化失敗、コンテキスト喪失時にはSVGイラストへ切り替えます。
- キーボード操作、見えるフォーカス、本文へのスキップリンク、日本語ラベル、意味のある見出し構造を用意しています。装飾用3Dと画像は支援技術から隠しています。
- 日本語フォントはGoogle Fontsを使用します。取得できない場合は端末のフォントで表示します。

実機の速度・発熱は端末とOSによって異なります。iPhone Safariの実機テストは別途必要です。画面サイズの検証結果は `QA.md` を参照してください。

## 編集する場所

| ファイル | 内容 |
| --- | --- |
| `index.html` | 日本語コピー、見出し、リンク、検索向け情報 |
| `src/style.css` | 配色、余白、書体、レスポンシブ表示 |
| `src/main.ts` | スクロール状態、章ナビ、3D切り替え |
| `src/scene.ts` | カメラ、照明、動き、軽量化設定 |
| `src/models.ts` | 4つの3Dモデルと質感 |
| `public/art/` | 3Dを使わないときのSVGイラスト |
| `.github/workflows/deploy.yml` | 公開の自動化 |

## 依存関係

`package-lock.json` でバージョンを固定しています。`npm audit --omit=dev` で配信時の依存関係を確認できます。

2026-11-18時点、開発用Viteの間接依存 `picomatch` に ReDoS の監査警告があります（GHSA-fc5q-39xc-vjpf、レジストリの最新版4.0.7にも該当）。これらの開発用ツールは静的サイトには配信されません。開発サーバーはループバック限定で起動します。修正版の提供後、依存関係を更新して再ビルドしてください。
